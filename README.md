# Components USA (public archive)

Public historical archive of **Components USA, LLC** marketing layouts built by
[Full Stack Boston](https://fullstackboston.com).

This is **not** a live client deployment, template, or starter kit. Real Firebase
project credentials are **not** included; `firebase.js` is a no-op stub.

**Live production** is private (`jonaldoalix/cusa.com`) and served on
[components-usa.com](https://components-usa.com) (prominent) with
[compact.components-usa.com](https://compact.components-usa.com) as an alternate.

Layouts in this archive:

- `prominent.components-usa.com/` — fuller marketing layout
- `compact.components-usa.com/` — compact marketing layout

```bash
npm ci
npm run lint:prod
npm run test:coverage
npm run build
```
